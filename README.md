# Claudesfield

An original browser football game: 3D broadcast camera, ball physics with spin, fictional teams, AI with five difficulty levels, referee, offside, set pieces and penalty shootouts.

```
npm install
npm run dev
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for how the code is organised.

## Playing

Pick two clubs, a side and a difficulty from **Play**, then kick off. Everything is rebindable in **Settings → Controls**, and gamepads (standard mapping) work out of the box.

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | W A S D / arrows | Left stick |
| Sprint | Left Shift | RT / R2 |
| Short pass (hold for pace) | J | A / Cross |
| Shoot (hold for power) | K | B / Circle |
| Lob pass / cross | L | X / Square |
| Through ball | I | Y / Triangle |
| Finesse shot (hold while shooting) | E | RB / R1 |
| Chip shot (hold while shooting) | C | LB / L1 |
| Skill: knock-on (moving) / drag-back (standing) | Space | R3 |
| Standing tackle (hold to close down) | J | B / Circle |
| Slide tackle | K | X / Square |
| Switch player | Q | LB / L1 |
| Pause | Esc / P | Menu / Options |

Tips: hold shoot longer for power, but over-hitting sends it over the bar. Aim shots with the movement direction. Pressing pass or shoot just before the ball arrives plays a first-time pass, volley or header. On penalties and close free kicks a reticle shows your aim. When facing a penalty you control the keeper: shuffle with left/right and dive with shoot.
